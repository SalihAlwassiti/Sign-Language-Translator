# Real-Time Sign Language Translator

A Raspberry Pi–based system that translates Arabic sign language into text using a camera, YOLOv8, and OLED display.

## Features
- Real-time gesture recognition
- Raspberry Pi compatible
- Modular and portable device
- Model trained on a custom-made dataset
- Supports Arabic letters

## Technologies
- Python Libraries: OpenCV, PyTorch, Ultralytics, YOLOv8, Picamera2
- Hardware: Arducam V3 (IMX519), 128x64 1.3In OLED LCD, Raspberry Pi 5
