# Real-Time Sign Language Translator

A Raspberry Pi–based system that translates Arabic sign language into text using a camera, YOLOv4, and OLED display.

## Features
- Real-time gesture recognition
- Raspberry Pi compatible
- OLED display output
- Supports Arabic letters

## Technologies
- Python, OpenCV, PyTorch, YOLOv4
- Raspberry Pi hardware

## Setup
1. Clone the repo
2. Run `pip install -r requirements.txt`
3. Launch with `python run.py`
